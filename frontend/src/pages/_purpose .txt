# Pages Folder

Purpose: Contains the main screens of the application that are mapped to routes and represent complete user views.

Examples:

- Home Page / Landing Page ✅
- Resume Upload Page
- Analysis Results Page
- Login Page
- Signup Page
- Profile Page

Guidelines:

- Focus on page structure and user flow.
- Compose pages using reusable components.
- Keep business logic minimal and delegate reusable functionality to components, contexts, hooks, or services.
